# 待测试

- 生图工作台、视频工作台结果面板顶部新增「全部展开/全部收起」按钮，统一控制所有结果卡片提示词的展开与收起；单张卡片自身的收起/展开按钮保留，仍可单独切换。
- 后台「工作流模板」编辑器新增模型配置：可选「图片生成模型」和多图模板的「提示词规划模型」，选项来自系统设置已启用渠道的可用模型；留空时用户端跟随自己的默认模型。
- 前台创作工作流卡片新增归属角标：不可编辑的模板按 `ownerUserId` 显示「平台模板」（金色）或「来自他人」（橙色），自己的模板不加角标，避免与重名的默认模板混淆。
- 前台工作流本地缓存按登录账号隔离（缓存 key 带上 userId），换账号登录不再读到上一个账号视角的编辑状态；未登录时使用独立 guest 缓存。
- 前台删除工作流失败时透传后端真实原因（如「只能删除自己的工作流」）并保留卡片；仅在后端接口不可用时才回退为本地移除。
- 画布左侧面板提示词列表改为分页加载：浏览时每页 50 条滚动到底自动加载；输入搜索词时才全量拉取分类数据做本地过滤（全量结果缓存 24 小时），避免首次展开就拉全量。
- 修复多图工作流后端任务模式点「生成」后永远停在「生成中」：创建后端任务后现在持续轮询状态（10 秒一次，超时上限取模板 timeout 配置），完成后回写草稿状态、任务卡图片和生图历史，并触发生图工作台结果回调；部分成功/失败、超时都有明确提示。
- 多图工作流草稿卡片直接展示生成结果缩略图（点击可放大预览），无需退出后去生图历史查看。
- 提示词中心改为左右两栏布局：分类与标签移到左侧竖向列表（标签支持多选、分类单选），右侧为搜索框与卡片网格。
