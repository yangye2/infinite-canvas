# 待测试

- 多参考图编辑：单张参考图使用 `image` 字段，多张参考图使用 `image[]`，验证 OpenAI 兼容渠道和中转接口均能正常生成。
- 画布多文本输入：普通生成链路将上游文本按 `【文本1】`、`【文本2】` 编号注入，验证提示词引用与实际文本块对应。
- GPT Image 生成和编辑：验证请求不会发送顶层 `response_format`，DALL-E 等其他模型仍保持原有 Base64 配置。
- 图片接口返回远程 URL：验证结果会优先下载为自包含数据，刷新页面后仍可显示；下载失败时保留原 URL。
- 我的素材下载：验证图片、视频、音频优先从本地或服务端 Blob 下载，标题包含中文、空格、路径符号时文件名仍安全有效。
- AI 日志脱敏：验证请求体、响应体、SSE 数据、URL 查询参数中的 `api_key`、`Authorization`、`token`、`secret` 等值不会以明文保存。
- 组节点生成输入：将组节点连接到生成配置节点，验证组内文本、图片、视频和音频会按稳定顺序参与生成，组不能作为目标节点被嵌套连接。
- 文本生成次数：验证配置中心和配置节点的文本生成次数独立于生图张数，切换模式和重试时配置不互相污染。
- 透明背景：验证配置中心、画布配置节点和提示词面板中的透明背景开关能写入生成请求，并在不支持的模型上不发送额外字段。
- 多图批次预览：验证多图根节点双击直接打开当前主图，张数按钮仍然负责展开和收起。
- 配置中心存储占用：验证能够显示浏览器存储已用空间和配额，浏览器不支持 Storage Estimate 时显示降级文案。
- 提示词中心缓存：验证相同查询条件在缓存有效期内不会重复请求，分页加载仍能继续获取后续结果。
- 生图工作台、视频工作台结果面板顶部新增「全部展开/全部收起」按钮，统一控制所有结果卡片提示词的展开与收起；单张卡片自身的收起/展开按钮保留，仍可单独切换。
- 后台「工作流模板」编辑器新增模型配置：可选「图片生成模型」和多图模板的「提示词规划模型」，选项来自系统设置已启用渠道的可用模型；留空时用户端跟随自己的默认模型。
- 前台创作工作流卡片新增归属角标：不可编辑的模板按 `ownerUserId` 显示「平台模板」（金色）或「来自他人」（橙色），自己的模板不加角标，避免与重名的默认模板混淆。
- 前台工作流本地缓存按登录账号隔离（缓存 key 带上 userId），换账号登录不再读到上一个账号视角的编辑状态；未登录时使用独立 guest 缓存。
- 前台删除工作流失败时透传后端真实原因（如「只能删除自己的工作流」）并保留卡片；仅在后端接口不可用时才回退为本地移除。
- 画布左侧面板提示词列表改为分页加载：浏览时每页 50 条滚动到底自动加载；输入搜索词时才全量拉取分类数据做本地过滤（全量结果缓存 24 小时），避免首次展开就拉全量。
- 修复多图工作流后端任务模式点「生成」后永远停在「生成中」：创建后端任务后现在持续轮询状态（10 秒一次，超时上限取模板 timeout 配置），完成后回写草稿状态、任务卡图片和生图历史，并触发生图工作台结果回调；部分成功/失败、超时都有明确提示。
- 多图工作流草稿卡片直接展示生成结果缩略图（点击可放大预览），无需退出后去生图历史查看。
- URL 导入渠道凭据：新的有效 `baseUrl` 应新增独立渠道且不修改已有渠道；再次导入相同 Base URL（含末尾斜杠或 `/v1` 变体）时只更新对应渠道并保持幂等；仅提供 API Key 或 Base URL 非法时所有配置保持不变。
- 图片 URL 下载：接口返回非图片 MIME（如 HTML 错误页）或空内容时应跳过并尝试下一个候选地址；下载超过 30 秒自动中断。
- 旧版多图批次画布：重新打开后应自动合并为单节点结果模型（缩略图条、主图切换、双击预览均可用），KIE 图层拆解和全景图批次保持原样。
- 多图单张失败重试：缩略图条中失败项显示「失败·点击重试」，点击后仅重新生成该张并回写原位置，其他结果不受影响。
- 多图单张下载/删除：悬停缩略图显示下载和删除按钮；下载保存原图；删除后剩余结果自动重新编号，删除主图时节点展示自动切换到下一张有效结果；删到只剩一张时收起展开状态。
- 提示词中心改为左右两栏布局：分类与标签筛选移到左侧栏（分类单选列表、标签多选流式换行，均复用现有 prompt-filter-tag 样式），右侧为搜索框与卡片网格。
